# Synthetic photo fixtures

Generated by `app/ai/fixtures/generate_image_fixtures.py`. Regenerate with:

    python -m app.ai.fixtures.generate_image_fixtures

These are **synthetic test images, not photographs of craft products**, and must
never be presented as artisan data or as evidence that the assessor works on real
photographs. Each filename names the single defect introduced into the base image.
They exist so the quality assessor has a deterministic regression harness that
runs in CI without a download.
